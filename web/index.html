Features

Everything you need, nothing you don't.

A focused tool built for developers and DBAs who work with real databases every day.

📄

Browse Table Data

Paginated data viewer with filtering, sorting, and inline cell editing. Export any result set to CSV, JSON, or SQL instantly.

🔧

Table Structure

Inspect and edit columns with full metadata: type, nullability, default, extra (AUTO_INCREMENT), charset, collation, and comment.

⌨

SQL Query Editor

Write and run raw SQL with syntax highlighting. Results appear instantly in a resizable grid. Query history is persisted across sessions.

🔗

Foreign Key Relations

Visualize foreign key constraints and understand how tables relate to each other without writing any SQL.

⚡

Triggers

View all triggers on a table, including event type (INSERT/UPDATE/DELETE), timing (BEFORE/AFTER), and the full trigger body.

📊

Table Info & Auto Increment

Row count, data size, index size, storage engine, collation, and CREATE TABLE DDL. Set a new AUTO_INCREMENT value with one click (MySQL).

🔑

Index Management

Create and drop indexes directly from the Structure tab. Choose columns, set unique, and pick index type (BTREE, HASH, or FULLTEXT for MySQL).

👥

MySQL User Manager

Manage MySQL accounts — create users, set passwords, grant global or per-schema privileges, and configure resource limits.

💾

Export & Migrate

Export tables or entire databases as SQL, CSV, JSON, or XML. Migrate data cross-engine with automatic type mapping and batch inserts.

🚀

Create Database Wizard

Step-by-step wizard to create a new database on any engine. For MySQL, choose character set and collation up front.

👥

Connection Management

Save multiple connection profiles with color-coded labels. SSH tunnel support for PostgreSQL. Reconnect in one click.

🌓

Light & Dark Theme

Follows your system preference automatically, or manually cycle between light, dark, and system modes.

Getting Started

Up and running in minutes.

No configuration files, no CLI setup. Just download, open, and connect.

1

Download & Install

Download the installer for your platform from dataace.anunes.net. Available for macOS (.dmg), Windows (.msi), and Linux (.AppImage / .deb / .rpm).

2

Add a Connection

Click the + button in the sidebar to create a new connection profile. Give it a name, choose your database type, and fill in the host, port, username, and password. For SQLite, click the folder icon to browse for a file.

3

Connect & Browse

Click your connection in the sidebar to connect. The database tree populates with all databases and tables. Click any table to start browsing its data in the Browse tab.

4

Inspect Structure & Manage Indexes

Switch to the Structure tab to see all columns with type, charset, collation, and comment. Add or edit columns and create or drop indexes — all without writing DDL manually.

5

Run SQL Queries

Switch to the Query tab to open the SQL editor. Write any query and press Cmd+Enter (macOS) or Ctrl+Enter (Windows/Linux) to run it, and see results immediately below.

6

Manage MySQL Users

When connected to MySQL, click the users icon in the sidebar footer to open the User Manager. Create accounts, set passwords, grant global and per-schema privileges, and configure resource limits.

7

Export or Migrate Your Data

Use the export menu to save a table or full database as SQL, CSV, JSON, or XML. Use the ⇄ migrate icon to copy data between databases of any supported type — cross-engine migrations included.

Adding & Editing Connections

Click the + button in the top-right of the sidebar to open the connection form. Fill in the details for your database and click Save. A successful connection saves the profile to the sidebar immediately.

FieldDescription
NameDisplay label shown in the sidebar.
TypeSQLite, MySQL, PostgreSQL, Oracle, or SQL Server.
ColorColor dot shown next to the profile for quick identification.
Host / PortServer address and port. Defaults are pre-filled per type.
Username / PasswordAuthentication credentials.
DatabaseOptional default database to select on connect.
Service NameOracle only — TNS service name (e.g. ORCL).

Right-click any profile in the sidebar for a context menu with Edit, Duplicate, Disconnect, and Delete options.

Opening SQLite Files

Click the folder icon in the sidebar header to open a native file picker filtered to .db, .sqlite, .sqlite3, and .db3 files.

After the file opens successfully, DataAce asks whether to Add to Connections or just Open Only:

  • Add to Connections — saves the file path as a named profile in the sidebar so you can reconnect later.
  • Open Only — connects for this session without saving.

SSH Tunnels

PostgreSQL connections support SSH tunnelling. Expand the SSH Tunnel section in the connection form and fill in:

  • SSH Host — the jump server hostname or IP.
  • SSH Port — defaults to 22.
  • SSH User — login username on the jump server.
  • SSH Password — password authentication.

DataAce opens the tunnel automatically on connect and tears it down on disconnect.

Sidebar & Navigation

The sidebar shows all saved connection profiles grouped by database type. Profiles with an active connection show a green dot. Click a profile to connect; right-click → Disconnect to close the session.

Refreshing — click the ↻ button in the sidebar header to reload the database and table list. You can also right-click any database and choose Refresh.

Once connected, expand a database to see its tables. Click a table to select it — the main area updates across all tabs. Right-click a database or table for options including Create Table, Drop Table, and Truncate.

Browse Tab

The Browse tab shows paginated rows for the selected table. Controls at the top let you adjust page size (25 / 50 / 100 / 250 / 500 rows).

Sorting

Click any column header to sort ascending; click again to sort descending.

Filtering

Click the Filter button to add filter conditions. Each condition lets you pick a column, an operator (=, !=, LIKE, >, <, IS NULL, BETWEEN, etc.) and a value. Multiple filters are AND-ed together.

Inline Editing

Double-click any cell to edit it in place. Press Enter to commit or Escape to cancel. Changes issue an UPDATE immediately. Click + row to insert a new empty row, or the trash icon to delete a row.

Exporting

Click Export in the Browse toolbar to save the current result set as CSV, TSV, JSON, XML, or SQL INSERT statements.

Structure Tab

The Structure tab shows two panels: Columns and Indexes.

Columns

Each row displays: name, data type, nullability, key membership (PRI / UNI / MUL), default value, and (when set) Extra, Character Set, Collation, and Comment. These extra columns appear automatically when any column carries values for them.

Use + Add Column or click the pencil icon on an existing row to open the column editor:

  • Name, Type, Nullable, Default
  • Extra — AUTO_INCREMENT or ON UPDATE CURRENT_TIMESTAMP (MySQL)
  • Character Set & Collation (MySQL only)
  • Comment (all engines)
  • Position — After column selector (MySQL)

Indexes

All indexes are listed with their type (PRIMARY, UNIQUE, INDEX, FULLTEXT), column list, and method (BTREE / HASH). Click + Add Index to create one:

  • Enter a name, select one or more columns via checkboxes.
  • Toggle Unique on or off.
  • Select index type: BTREE (default), HASH (MySQL only), FULLTEXT (MySQL only).

Click the trash icon on any non-primary index row to drop it.

Query Tab

A full SQL editor with syntax highlighting, auto-resize, and a resizable result pane below.

ShortcutAction
Cmd/Ctrl + EnterRun the query (or selected text only)
Cmd/Ctrl + ↑ / ↓Navigate query history

Results show row count, execution time, and an exportable grid. Non-SELECT statements show rows-affected feedback. Errors appear inline below the editor. The editor remembers the last query per connection across sessions.

Relations Tab

Shows all foreign key constraints associated with the selected table — both outbound (this table references another) and inbound (other tables reference this one).

Each row shows the constraint name, local column(s), referenced table, referenced column(s), and the ON DELETE / ON UPDATE rules.

Triggers Tab

Lists all triggers defined on the selected table:

  • Name — trigger identifier.
  • Event — INSERT, UPDATE, or DELETE.
  • Timing — BEFORE or AFTER.
  • Body — the full trigger statement, shown in a monospace block.

Info Tab

When a table is selected, Info shows:

  • Row Count, Data Size, Index Size, Total Size
  • Storage engine and collation (MySQL)
  • Created date and table comment
  • Auto Increment — current value, with a Set widget to change it (MySQL only). Enter a new value and click Set to issue ALTER TABLE … AUTO_INCREMENT = N.
  • Full CREATE TABLE DDL

When no table is selected but a database is, Info shows database-level metadata including character set, collation, and schema summary.

Creating a Database

Click the database icon in the sidebar to open the New Database wizard. Two steps:

  1. Connection — select the database type and fill in connection details. Click Test & Continue.
  2. Database — enter a name. For MySQL, also pick:
    • Character Set — utf8mb4 (recommended), utf8, latin1, ascii.
    • Collation — options update automatically based on the chosen charset.

For SQLite, name your database and pick a save folder. Leaving the folder blank creates an in-memory database.

Exporting Data

Table Export

With a table selected, click Export in the Browse toolbar. Choose: CSV, TSV, JSON, XML, or SQL (INSERT statements).

Database Export

Click Export DB in the sidebar bottom bar. Options:

  • Format: SQL dump, CSV, JSON, or XML.
  • Structure + Data or Structure Only.
  • Per-table selection — choose which tables to include.

Migrating Data

Click the ⇄ (arrows) icon in the sidebar footer to open the Migration Wizard. Four steps:

  1. Source — pick an active source connection, select a database, then check the tables to migrate.
  2. Target — pick any saved connection profile (DataAce auto-connects if needed). Select a target database, or choose ＋ Create new database… to create one on the fly.
  3. Type Mapping — pre-filled table showing source column types mapped to the target engine. Edit any cell to override.
  4. Execute — DataAce creates each table on the target and streams data in 500-row batches. A progress bar per table and a live log show status.
Cross-engine migrations are supported. For example, migrate a MySQL database to PostgreSQL — type mappings (e.g. TINYINT(1) → BOOLEAN, DATETIME → TIMESTAMP) are applied automatically and can be adjusted in step 3.

MySQL User Manager

Click the users icon in the sidebar footer to open the User Manager. The icon is only enabled when a MySQL connection is active.

The modal lists all MySQL accounts grouped by username. Click a username to expand its hosts, then click a specific user@host entry to load that account for editing.

General Tab

FieldDescription

Click Save Changes to apply. Create a new account with + New User at the top of the user list.

Global Privileges Tab

Toggle server-wide privileges using checkboxes organised into groups:

  • Data — SELECT, INSERT, UPDATE, DELETE, FILE
  • Structure — CREATE, ALTER, INDEX, DROP, CREATE TEMPORARY TABLES, SHOW VIEW, CREATE ROUTINE, ALTER ROUTINE, EXECUTE, CREATE VIEW, EVENT, TRIGGER
  • Administration — GRANT, SUPER, PROCESS, RELOAD, SHUTDOWN, SHOW DATABASES, LOCK TABLES, REFERENCES, REPLICATION CLIENT, REPLICATION SLAVE, CREATE USER

Schema Privileges Tab

Grant per-database privileges. Select a schema from the left panel, then check or uncheck individual privileges in the right panel. Click Save Changes to apply GRANT … ON schema.* TO user@host.

Resources Tab

Configure per-hour and per-connection resource limits (same fields as the General tab, presented for convenience alongside other settings).

Themes

Click the theme icon (sun / moon / monitor) in the top-right of the sidebar to cycle between three modes:

  • Light — white background, dark text.
  • Dark — dark background (default).
  • System — follows your OS appearance setting automatically.

Your preference is saved and restored across sessions.
